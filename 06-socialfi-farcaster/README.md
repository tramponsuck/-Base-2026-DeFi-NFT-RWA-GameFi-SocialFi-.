# 06. SocialFi & Farcaster

**Farcaster** — главный социальный протокол на Base.

## Ключевые проекты
- **Farcaster** + Frames
- **Friend.tech** (v2 или аналоги)
- Децентрализованные социальные приложения

## Как участвовать
1. Создай аккаунт на Farcaster
2. Покупай/продавай Social Tokens
3. Используй Frames для мини-приложений
4. Построй on-chain репутацию

SocialFi + Base = мощный инструмент для сообществ и creators.
