# 04. RWA (Real World Assets)

## Что такое RWA на Base?
Токенизация реальных активов: Treasuries, private credit, недвижимость, акции.

## Ключевые проекты на/для Base (2026)
- **Grand Base** — synthetic RWAs и спот-трейдинг
- **Ondo Finance** (OUSG, USDY) — tokenized Treasuries
- Интеграции **BlackRock BUIDL**
- **Centrifuge** — private credit (работает кросс-чейн)
- **Maple Finance** — institutional lending

## Как начать
1. Купи tokenized Treasuries (yield 4-8%+)
2. Используй их как collateral в DeFi
3. Следи за новыми синтетическими продуктами

**RWA — одно из самых перспективных направлений 2026 года.**
