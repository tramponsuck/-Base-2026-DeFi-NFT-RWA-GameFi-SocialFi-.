# 03. NFT Маркетплейсы и Коллекции

## Основные маркетплейсы
- **OpenSea** — самый крупный на Base
- **Magic Eden** — удобный интерфейс
- **Element Market**, **Blur** (если поддерживает), **SNFT**

## Популярные направления NFT на Base
- Коллекции PFP
- NFT для игр (GameFi)
- Music NFT и AI-generated
- RWA-backed NFT (токенизированная недвижимость, искусство)

**Совет:** Покупай Basename (.base) — это тоже часть NFT-инфраструктуры Base.
